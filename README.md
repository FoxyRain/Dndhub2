# 🎲 D&D Hub

Сайт-хаб для игры в Dungeons & Dragons.

## Функции
- 📜 Кампании - список и описание кампаний
- 🗺️ Карты - просмотр карт с метками
- 🎯 Инструменты - кубики, инициатива, генераторы

## Технологии
- HTML5
- CSS3
- JavaScript (vanilla)
- GitHub Pages (бесплатный хостинг)

## Как открыть
Просто откройте `index.html` в браузере или зайдите на [сайт](https://foxyrain.github.io/Dndhub/)
